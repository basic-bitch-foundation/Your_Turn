# Your_Turn
 It is a Godot based Knife throwing game and aiming at apple while log on which apple spawn in quantitiy according to rounds!
 ## Controls
 Just click **Play** button and click on free space to fire/ throw the knife at right time
 ## Installation
 U don't have to isntall game :yayayay: u can just spawn your cursor on this link and **Enjoy!**.
